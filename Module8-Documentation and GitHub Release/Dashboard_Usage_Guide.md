# Dashboard Usage Guide

## Introduction

This guide explains how to use the Unified Military Analytics dashboard.

The dashboard provides four major sections:

1. Quick Stats
2. Nation Overview
3. Compare Powers
4. Coalition Builder

---

## 1. Quick Stats

Quick Stats provides an overall view of global military capabilities.

### Filters

Users can filter the data using:

- Country
- Region
- Continent
- Alliance

### Information Available

The dashboard can be used to explore:

- Power Index
- Defense Budget
- Military Personnel
- Aircraft
- Naval Fleet
- Military rankings

### How to Use

1. Open the dashboard.
2. Navigate to Quick Stats.
3. Select the required filters.
4. Review the updated KPI values.
5. Explore the displayed rankings and military statistics.

---

## 2. Nation Overview

Nation Overview provides detailed information about a selected country.

### How to Use

1. Navigate to Nation Overview.
2. Select a country.
3. View its military profile.
4. Review its Power Index and ranking.
5. Review defense budget and manpower.
6. Explore aircraft, helicopters, tanks and naval capabilities.

### Key Information

The section provides information such as:

- Power Index
- Power Index Rank
- Defense Budget
- Active Personnel
- Reserve Personnel
- Military Aircraft
- Military Helicopters
- Tanks
- Naval Fleet

---

## 3. Compare Powers

Compare Powers allows users to compare two countries.

### How to Use

1. Navigate to Compare Powers.
2. Select the first country.
3. Select the second country.
4. Review the side-by-side comparison.

### Comparison Metrics

The dashboard compares:

- Power Index Rank
- Defense Budget
- Active Personnel
- Military Aircraft
- Naval Fleet

This makes it easier to identify differences between two military powers.

---

## 4. Coalition Builder

Coalition Builder allows users to create a multi-country military coalition.

### How to Use

1. Navigate to Coalition Builder.
2. Select multiple countries.
3. Select a reference country.
4. Review the combined coalition statistics.
5. Compare the coalition against the reference country.

### Coalition Metrics

The dashboard calculates combined:

- Defense Budget
- Active Personnel
- Military Aircraft
- Naval Fleet

---

## 5. KPI Interpretation

### Power Index Rank Gap

A positive or negative rank gap indicates the difference between economic ranking and military power ranking.

### Assets per Capita

A higher value indicates more military assets relative to population.

### Budget-to-GDP Ratio

This indicates the proportion of GDP represented by defense spending.

---

## 6. Tips for Using the Dashboard

- Use filters to narrow the analysis.
- Use Nation Overview for detailed country-level analysis.
- Use Compare Powers when analyzing two countries.
- Use Coalition Builder when analyzing multiple countries.
- Check the selected countries before interpreting comparison results.
- Use the KPIs together rather than relying on a single indicator.
