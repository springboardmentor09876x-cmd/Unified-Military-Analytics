# 🛡️ Unified Military Analytics - Module 5

## 📌 Project Overview

Module 5 of the **Unified Military Analytics** project focuses on developing an interactive Streamlit dashboard that provides a comprehensive overview of global military capabilities. The dashboard enables users to explore military data, analyze defense-related statistics, and gain strategic insights through interactive visualizations.

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/springboardmentor09876x-cmd/Unified-Military-Analytics.git
```

### Navigate to Module 5

```bash
cd "Module5-Build Quick Stats and Nation Overview Dashboards"
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
streamlit run dashboard_application.py
```
