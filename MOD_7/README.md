# Module 7 – Testing and Debugging

## Project Overview
This module covers the final testing and debugging phase of the **Military Dashboard** project, completed as part of Weeks 7–8 (Final Review and Delivery).

## Module Objective
To test and validate the Military Dashboard and ensure that all filters, parameters, navigation, data values, charts, tooltips, labels, and dashboard layout work correctly, and that the workbook runs smoothly ahead of final delivery.

## Testing Performed
- Dashboard loading and performance
- All filters, individually and in combination
- All parameters
- Dashboard and page navigation, including navigation buttons
- Charts and visualizations
- Manual spot checks of displayed data values against source data
- Tooltips
- Titles and labels
- Layout and alignment
- Interactive elements
- Cross-dashboard consistency
- End-to-end functionality
