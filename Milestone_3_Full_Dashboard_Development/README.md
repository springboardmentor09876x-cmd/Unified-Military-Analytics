# 🎯 Unified Military Analytics - Milestone 3

## 📌 Project Overview

**Milestone 3: Full Dashboard Development** focuses on developing interactive dashboards for analyzing global military capabilities.

This milestone includes **Module 5: Quick Stats & Nation Overview** and **Module 6: Compare Powers & Coalition Builder**. The dashboards allow users to explore country-level military capabilities, compare military powers, analyze coalition strength, and gain insights through interactive visualizations and filters.

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/springboardmentor09876x-cmd/Unified-Military-Analytics.git
```

### Navigate to Milestone 3

```bash
cd "Unified-Military-Analytics/Milestone 3: Full Dashboard Development"
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Virtual Environment

For macOS/Linux:

```bash
source venv/bin/activate
```

For Windows:

```bash
venv\Scripts\activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
streamlit run app.py
```

The application will open at:

```text
http://localhost:8501
```
